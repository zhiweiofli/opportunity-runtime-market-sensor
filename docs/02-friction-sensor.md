# Friction Sensor

## 1. 使命

Friction Sensor 负责发现：

> **已经存在的资金流中，哪些摩擦正在造成收入、转化或成本损失。**

不是寻找“烦人的体验”。

而是寻找：

> **Economic Leakage。**

---

## 2. 重点观察的摩擦

- Discovery
- Install
- Onboarding
- Setup
- Configuration
- Migration
- Integration
- Payment
- Authentication
- Localization
- Compliance
- Cross-device
- Cross-platform
- Support
- Manual operation

---

## 3. 核心判断

任何 Friction Signal 必须回答：

1. 谁因为这个 friction 损失钱？
2. 损失的是：
   - revenue
   - conversion
   - CAC
   - labor
   - time
   - churn
   - failed transaction
3. 当前 workaround 是什么？
4. workaround 本身花多少钱？
5. 谁会为消除 friction 付钱？

如果只是：

> “用户觉得很烦”

不够。

---

## 4. 优先原始素材

### 用户行为

- App Store / Google Play Reviews
- Reddit 原帖 / 评论
- GitHub Issues / Discussions
- Support Forum
- YouTube Comments
- 产品社区

### 工作流证据

- 安装文档
- Setup Guide
- Migration Guide
- Integration Docs
- Pricing Page
- Changelog
- FAQ
- Support 文档

### 更强经济证据

- 用户已经付费
- 高价订阅仍需人工 workaround
- 第三方服务收费处理该 friction
- 企业专门雇人处理
- 明确的 lost conversion / lost revenue / labor cost

---

## 5. 优先寻找的模式

强信号：

> **Already paying + Still doing manually**

例如：

- 已经付 $100/月 SaaS，仍每天导出 CSV
- 已购买工具，仍要人工同步
- 已有平台，但迁移必须找顾问
- 已经购买服务，但安装 / 配置仍需要大量人工

这类信号明显强于：

> “希望有一个 App 可以……”

---

## 6. Friction Value

不需要精确计算，但应尽量回答：

```text
Friction Value
≈ Frequency
× Economic Loss per Event
× Recoverable Rate
```

至少需要知道：

- 发生频率
- 每次经济影响
- 是否可以恢复其中一部分价值

---

## 7. Signal 格式

```text
Signal

Friction
具体哪个环节有问题？

Money
哪笔钱因此损失或增加成本？

Evidence
2–4 条原始行为证据。

Current Workaround
用户现在怎么绕过去？

Payer
谁最可能为解决它付钱？

Economic Effect
conversion / revenue / labor / churn / cost

Persistence
Temporary / Structural

Next Question
最值得验证的经济问题是什么？
```

---

## 8. 触发 Research

至少满足：

- 已存在真实经济活动
- friction 重复出现
- 能连接到经济损失
- 有 payer 或当前 workaround 成本
- 不是平台马上会解决的单点问题

否则保持 WATCH。

---

## 9. 快速 Kill

优先 Kill：

- 只有抱怨，没有经济损失
- 免费用户很多，但无付款意愿
- 一次性 bug
- 已有简单标准答案
- 平台下一版原生功能即可解决
- 需要大量客服 / 售后
- 价值很小但实施很重
- 用户根本不愿切换 workaround

---

## 10. Sensor 不应该做什么

不要：

- 自动跳到产品设计
- 自动设计 App
- 用“痛点强烈”代替“经济价值”
- 用评论数量代替付费意愿

它只负责回答：

> **哪里的钱因为摩擦没有顺利流动？**
