## 范围与方法

通过已连接的 Drive 只读列举用户指定的根目录及子目录，按文件 ID 与 `or-archive/manifest.json` 对照。逐项尝试读取文件正文，检查标题元数据及状态、摘要、标签的字段形态；这不是对每份文档论证或导出格式保真度的人工审核。源文件夹私有、目标仓库公开；本记录不复制源正文。

## 页面字段

- 标题可从 Drive 文件元数据取得；研究机会的更易读标题并非全部使用同一字段，现有索引使用明确的正文标题或文件名回退。
- 现有 83 份镜像均能生成正文摘录，不等于原文自带标准摘要、摘要语义经过审核，或 Drive 全目录均可用同一规则处理。
- 现有镜像中的 78 份 Research 都可读取出原文最终状态；5 份 Judge 没有对应的 Research 最终状态，不能硬套。源目录中的 Signals、Judge、回执与 Research 使用不同状态语义，不能合并成一个统一业务阶段。
- 对已取得文本的字段标记做机械扫描，没有识别到统一的 `tags`/`labels` 标签字段；这不排除某份文档在其他位置或以其他格式表达主题。页面暂以 Research 文件名中明确写出的 IBF、UW、Business、Friction 作来源标签，不推断主题。
- 现有页面对 83 份镜像支持类型、原文最终状态、来源标签和标题/摘录搜索；尚不覆盖未入镜像的文件，不能作为全目录完整索引。

## 同步结论

GitHub Actions 通过独立 Google 身份、文件夹只读授权与 Drive API 可以实现单向读取，认证和导出约束见 [Drive 同步调研](drive-actions-sync-research.md)。当前没有配置 Actions 的 Drive 访问身份，也未证明其能读取目标文件夹；此次检查不启动同步。目标仓库公开，整目录同步会公开所有同步的正文和 Git 历史，应先确认发布范围与目标仓库。
