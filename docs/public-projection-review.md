## 拟发布内容

只使用已核验记录中单独填写的 `public` 字段，以及下列系统派生内容。原始字段不会自动复制或由模型改写成摘要。

| 来源 | 拟公开的字段 |
| --- | --- |
| 机会的 `public` | 脱敏标题、摘要；如单独填写，还包括客户类别摘要、金额锚点（数值、币种、单位、实测/估算/未知）、四 Gate 摘要、关键未知摘要、下一步摘要 |
| 任务的 `public` | 如单独填写，问题摘要、判定标准摘要、预算金额（数值、币种、单位、依据） |
| 结果的 `public` | 如单独填写，结果摘要和实际费用（数值、币种、单位、依据） |
| 系统派生 | Judge 建议、有限枚举的研究状态、流程阶段、等待时间、实际事件时间、匿名角色（人类 / Judge / 实践 Agent / 中心回执）、任务及机会聚合数、完成率、立项转化、各项新鲜度时间 |
| GitHub 链接 | 对应私有仓库的 PR / Issue 链接；页面标明需要仓库权限。链接本身会公开仓库路径和编号。 |

数字统计使用最近 90 天的创建批次，并显示样本数和观察截止时间。未公开字段显示“未公开”，未知值显示“未知”，零分母显示“无样本”。synthetic 记录不进入业务卡片或业务指标；未通过或待验证的提案数是运行状态，可能包含测试提案并明确标注。

**新投影不发布**原始 Research/Judge 正文、未写入 `public` 的客户信息、原始证据、个人决定理由、任务或运行 ID、评论正文、消费者账号、凭据或内部错误日志。代码只能保证字段白名单；无法证明人工填写的摘要没有包含敏感内容，每次评审仍需人工检查。

## 与旧页面的关系

旧 `site/data/latest.json` 和现有 Judge 视图保留。若启用 Pages，旧文件也会随 `site/` 一起发布；它包含此前整理的脱敏机会与人类决策摘要，也必须纳入本次范围确认。新投影生成失败时不部署新的 artifact，现有页面保留并展示最后一次快照时间；页面按时间提示可能过期。

确认范围后，另行核对仓库 Pages 资格、用户允许公开的字段及各记录的脱敏内容，再决定是否将 `WORKFLOW_PUBLIC_PROJECTION_APPROVED` 设为 `true` 并启用部署。当前私有仓库 Pages API 返回 404，尚无已签收的公开 URL。
