候选事件 1：Canva 全面开放 Canva MCP（GA）并上线 Service Accounts 与 REST API 计费（2026-11-23）
* 事实摘要：根据 Canva 官方新闻稿 Building the design layer of the internet: opening Canva to every agent and developer，Canva 于 2026 年 11 月 23 日取消候补名单全面开放 Canva MCP，并推出新版 REST API（支持设计生成、Magic Layers、Canva Craft 图像模型）、扩展 Canva CLI 以及支持高并发自动化的 Service Accounts 与 API 计费机制（允许外部产品终端用户无需登录 Canva 账号即可调用设计能力）。Canva 披露自 10 月以来已有近 50 万人通过 MCP 注册，预期年经常性收入（ARR）9 至 10 月环比增长逾 300%。
* 门槛对照与过滤原因：未通过门槛 1（明确的一手单价/费率凭证）与门槛 5（小团队可捕获路径待验证）。新闻稿虽披露了增长指标与 API 计费功能上线，但未公开 REST API 与 Canva Craft 模型的具体调用单价、阶梯扣费表或分成比例；且在此结构中 Canva 自身作为底层创意收费站直接向集成方收费，尚需进一步核实其公开费率表及 Magic Layers 自动化批量生成能否在垂直电商/营销物料领域形成显著的毛利位移，列入重点 WATCH。
候选事件 2：Anthropic 公测 Enterprise Frontier Safeguards（EFS）兼容零数据保留（2026-11-23）
* 事实摘要：Anthropic 官方博客发布 Zero data retention with Enterprise Frontier Safeguards is now in beta，向金融、医疗与法律等强监管企业开放 EFS 公测，允许客户将日志保留在自有 AWS S3 或 Google Cloud Storage（使用自有密钥加密），由 Anthropic 执行自动化跨请求安全监测并生成 Safety Case。
* 门槛对照与过滤原因：未通过门槛 1（一手独立定价凭证）与门槛 5（小团队捕获路径）。属于面向财富 100 强企业的安全合规能力补齐，部署渠道主要依托埃森哲、德勤、毕马威与普华永道等大型咨询伙伴，无独立收费账单披露，亦不符合 3–5 人轻资产小团队的切入约束，列入 IGNORE。
