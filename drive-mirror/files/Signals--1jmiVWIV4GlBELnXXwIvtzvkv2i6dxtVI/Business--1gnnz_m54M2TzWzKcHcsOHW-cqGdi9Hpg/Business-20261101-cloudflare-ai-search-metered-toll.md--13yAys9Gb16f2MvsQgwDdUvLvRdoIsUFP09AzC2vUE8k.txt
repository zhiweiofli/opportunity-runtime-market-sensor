Signal ID: Business-20261101-cloudflare-ai-search-metered-toll
* Type: Business
* What Changed: 2026年11月1日，全球最大边缘网络服务商 Cloudflare 官方正式对旗下 AI Search（将 Workers AI 嵌入模型、Vectorize 向量库、R2 存储及 Browser Run 爬虫整合为一体的无服务器搜索管道）全面开启正式计量扣费（Usage-based billing）。根据 Cloudflare 官方于 2026年10月30日 最新更新的配额与价目表（Limits & Pricing），平台在每月附赠基础额度（500万摄入 Token、10 GB 存储、1,000 次语义查询及 1,000 次全文检索）之外，正式执行严格的五重按量阶梯费率：基础数据摄入 $0.75 / 100万 tokens、图片与 PDF OCR 额外加收 $0.50 / 100万 tokens（合计 $1.25/M）、索引内置存储高达 $2.00 / GB-月、语义/向量/混合检索查询 $0.75 / 1,000 次、全文检索 $0.10 / 1,000 次，并在 Workers Paid 上对超出 5,000 个实例的租户按 $0.10 / 实例/月 收取架构隔离费。此变更属于典型的 New Toll Booth（Cloudflare 在全球边缘节点上正式焊死知识检索与智能体 RAG 调用的过路收费站）与 Budget Migration（企业检索增强生成 RAG 与企业知识库预算，从传统独立向量数据库与复杂云端抓取管线，全面迁移至边缘一体化托管计费服务）。
* Money: 涉及全球使用 Cloudflare Workers 架构部署企业知识库、客服检索与自主智能体（AI Agents）的数十万开发者与企业应用预算。此前 AI Search 处于免费公测期，开发者可零边际成本索引数百万网页并高频执行多智能体并发检索；新规下，检索与存储费用发生剧烈分化。尤为关键的是，$2.00 / GB-月的存储单价是 Cloudflare 标准 R2 对象存储（$0.015 / GB-月）的 133 倍，且系统规定按分块分词（cl100k_base）后的所有重叠文本（Chunk Overlap）重复计算摄入与存储。这意味着一个日均处理 50 万次智能体检索、保留 50GB 动态知识库的中型应用，每月仅检索调用费即达 $375，存储费达 $100，瞬间形成数倍于 Workers Paid 基础席位（$5/月）的高额按量流水账单。
* Evidence:
   * Cloudflare 官方开发者文档与最新定价标准《Limits & pricing - Cloudflare AI Search docs》（文档最后更新日期：2026-10-30，计费执行生效日：2026-11-01）：官方明确公布计费细则"AI Search billing begins on November 1, 2026... Base ingestion: $0.75 per million tokens; Image processing: An additional $0.50 per million tokens; Storage: $2.00 per GB-month; Semantic, vector, and hybrid queries: $0.75 per 1,000 queries; Full-text queries: $0.10 per 1,000 queries; Instances above 5,000: $0.10 per additional instance per month"。
   * Cloudflare 官方博客通用可用性公告《AI Search is now generally available》（发布日期：2026-10-01，计费提醒更新：2026-10-30）：官方披露技术整合架构"combines Workers AI, Vectorize, R2, and Browser Run into a fully managed index and retrieval pipeline... support multimodal formats beyond text, adding native image embeddings, OCR for PDFs... start billing for AI Search on November 1, 2026"。
   * Cloudflare Changelog 官方发布《AI Search is generally available》（2026年10月发布）：确认自 2026年11月1日 起，AI Search 从 Beta 测试全面转为正式商业计费，并将原专用于爬虫的独立 R2 bucket 整合归入 $2.00/GB 的内置托管存储。
* Mechanism:
   * 边缘网络从"管道传输"到"智能体检索收税"的战略跃迁（事实）：Cloudflare 占据全球超 20% 网站的 DNS 与 CDN 流量入口。过去其主要变现方式为带宽、安全规则与基础 Workers 算力；通过推出 AI Search，Cloudflare 将非结构化文档直接转化为智能体可用向量，并在查询端（$0.75/1k）和存储端（$2.00/GB）设立高毛利计量卡点（New Toll Booth），成功收割了原本流向 Pinecone、Weaviate、Qdrant 的外部基础设施预算。
   * 内置存储 133 倍剪刀差与文本重叠分块膨胀（事实/推断）：RAG 系统为确保语义连续性，必须在相邻分块间保留 10%–20% 的重叠文本（Chunk Overlap）。官方确认"重叠文本在每个分块中均被独立计费"，导致企业实际摄入与存储账单呈倍数级虚增，且 $2.00/GB 的存储税直接逼迫开发者进行存储精细化治理。
   * 小团队轻资产进入节点（推断）：
      * a. Cloudflare AI Search 分块压缩与双层存储去重中间件（RAG Storage Compressor）：针对 AI Search 高达 $2.00/GB-月的存储暴利，开发轻量前置处理库/中间件。在文档提交索引前，自动通过轻量算法消除冗余样板代码、压缩语义重复段落、并根据查询频次将冷文档降级至廉价 R2（$0.015/GB）只提供关键词索引，仅将高频热向量推入 AI Search 内置存储，直接帮出海开发团队削减 60%–80% 的 AI Search 存储与摄入账单。
      * b. 查询意图智能分流网关（Semantic-to-Fulltext Query Router）：由于语义/混合检索（$0.75/1k）价格是全文检索（$0.10/1k）的 7.5 倍，构建一个运行在边缘轻量 Workers 上的微型分类器。当用户查询属于精确关键词（如型号、ID、专有名词）时，自动路由至 $0.10/1k 的全文检索通道；仅当包含复杂自然语言推理时才放行至 $0.75/1k 语义通道，直接大幅降低查询端过路费。
      * 极度符合 1–3 人小团队形态：纯边缘代码（TypeScript/Workers）、无服务器架构、零实体资产、高毛利开发者工具订阅。
* Magnitude: Large。依据：Cloudflare 拥有全球数百万开发者与覆盖全球的边缘网络底座，AI Search 正式启动商业计费标志着边缘 RAG 成为公有云基础设施核心变现模块，深远改变了企业智能体检索的数据管线采购结构。
