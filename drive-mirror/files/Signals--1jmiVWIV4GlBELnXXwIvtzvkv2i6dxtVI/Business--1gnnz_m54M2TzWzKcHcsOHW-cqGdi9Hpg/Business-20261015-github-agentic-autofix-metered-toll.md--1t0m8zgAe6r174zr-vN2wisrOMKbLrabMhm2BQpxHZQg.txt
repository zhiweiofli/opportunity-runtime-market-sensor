* What Changed: 2026年10月15日，GitHub 官方正式宣布面向 GitHub Enterprise Cloud 用户全面开放代码扫描告警自主修复（Agentic autofix for code scanning alerts）通用可用性（General Availability, GA）。关键的商业机制变更为：Agentic autofix 官方正式取代了此前在单个代码扫描告警上完全免费的"Generate Fix"选项，变更为"Assign to Copilot"工作流；且强制要求企业配置 Copilot 账单结算方式（Copilot billing method），该修复执行将从企业的 Code Security 预算中直接扣除 AI Credits，并同步计费扣减 GitHub Actions 计算分钟数（Actions minutes）。该变更属于 New Toll Booth（对过往免费的代码安全修复辅助设置必经的计量消耗卡点）与 Budget Migration（代码漏洞修复支出从研发内部人工排查工时或固定的 Advanced Security 席位授权，迁移为按修复任务触发的 AI Credits 与 Actions 算力计量预算）。
* Money: 涉及使用 GitHub Enterprise Cloud 及 GitHub Advanced Security (GHAS) 的全球中大型企业研发与应用安全（AppSec）预算。此前单个告警生成修复建议属于平台随附的免费辅助工具（0 边际成本）；新规下，企业必须接入 Copilot 结算通道，每次指派修复均直接消耗 Code Security AI Credits 额度并产出 Actions runner 计费分钟数。针对历史积压数千至数万条安全告警的大型代码库，若批量执行自主修复（支持单次聚合最多 25 条 alerts 进单个 PR），单月将产生数百至数千美元不等的 AI 信用与 CI 算力新增支出，迫使企业管理员必须在企业后台单独配置 SKU 级别的 Code Security AI Credits 预算上限与消费熔断。
