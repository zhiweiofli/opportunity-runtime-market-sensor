Signal ID: Business-20261104-smartthings-cloud-api-paid-toll
* Type: Business
* What Changed: 2026年11月4日，全球最大智能家居与消费级 IoT 生态之一的三星 SmartThings 官方正式终结长达十余年的免费开放云端 API 历史，正式上线面向独立开发者与商业合作伙伴的付费 API 计划（Paid API Plans for Developers and Business Partners）。官方确立明确执行时间轴：免费访问仅开放至 2026年11月3日 截止；自 2026年11月4日 起，所有通过 OAuth 直接调用 SmartThings 云端 API（Direct Open Authorization Cloud API Calls）的个体开发者与商业集成均正式转为付费订阅（Paid）；若未在 2026年12月15日 前签约付费方案，所有未付费的云端 API Key 将在云网关层（Gateway Level）被强制注销与冻结，阻断一切自动化调用。具体方案包括：面向独立开发者的 Developer Plan（每月固定底费，包涵每月 100,000 次云 API 调用额度及跨物理位置最多 10 个激活应用安装）；以及面向商业平台（如 Airbnb/VRBO 智能短租管理、商用建筑能源平台、PropTech 自动化运维）按调用量阶梯收费的 Business Plan。本地 Edge Drivers 保持免费，但远程 Rules 与 CLI 云端应用创建被强制锁入付费订阅。此变更属于典型的 New Toll Booth（三星在连接数亿台智能家电、电视与智能门锁的云端控制管道上正式设立强制收费站）与 Budget Migration（商业物业自动化、短租软件与智能家居中继服务商的运维预算，被迫从零成本免费云调用向月度商业 API 订阅或本地化网关改造迁移）。
* Money: 涉及全球数以万计依托 SmartThings 云端集成管理商业物业（民宿短租门锁密码下发、公寓空调定时控制、商用照明与安防）的 PropTech 企业、B2B 物联网 SaaS 及数十万高阶智能家居开发者的运营预算。过往第三方商业短租平台（如 Guesty、Hospitable 等民宿管理系统）可免费调用 SmartThings 云端接口实现无感自动下发门锁密码与入住水电联动；新规下，商业实体必须与三星签约阶梯式按量付费 Business Plan，或者迫使每个业主/房东单独掏钱购买 Developer Plan（每月限额 10 万次调用与 10 个安装位）。对于管理上百套房源的商业短租运营商，每月将产生数百至数千美元不等的云端 API 固定与弹性开销；若在 12月15日 前未完成付费迁移，全网智能门锁与温控自动联动将在网关层瞬间瘫痪。

Free Access through November 3, 2026... Direct Open Authorization (OAuth) Cloud API Calls (Individual Developer Use): Paid; Business API Usage: Paid"；公布配额限制"The quota is up to 100,000 cloud API calls per month and up to 10 active app installs across locations"；并设定网关级清退死线"December 15, 2026 and after: If an API Access App owner does not select a paid plan by December 15, 2026, access to their API integrations may be limited, paused, or discontinued. Active API keys will be deactivated, and automated calls... will be paused at the gateway level"。

   1. 云端轮询与状态推送成本的商业收割（事实）：作为全球消费级 IoT 龙头，三星云端长期无偿承载着第三方平台数以亿计的高频轮询（Polling）与设备状态推流，服务器带宽与长连接维护开销巨大。三星通过在 11月4日 设立 Developer Plan（10 万次封顶）与 Business Plan，并将实时事件流 Server-Sent Events (SSE) 绑定为付费权益，成功在智能家居与商业设备的云端控制权上设立了必经收费站（New Toll Booth）。
   2. 倒逼"云端按量付费"与"本地边缘化（Edge Drivers）"的二元分化（事实/推断）：官方将本地 Edge 驱动保持免费，但对跨互联网的远程 OAuth 控制实施按量收费。这直接倒逼商业短租与物业 SaaS 进行架构重构：要么接受三星的月度 API 商业账单，要么转向本地局域网网关调度。
   3. 小团队轻资产进入节点（推断）：

      * SmartThings 云 API 配额压缩与 SSE 事件聚合代理（Cloud API Quota Compressor for SmartThings）：针对必须保留云端跨外网控制的企业开发者，开发轻量中继缓存代理。利用付费方案附带的 SSE 机制替代传统高频 Polling，将多租户状态查询合并为统一事件广播，确保调用量严格压制在 100,000 次开发者配额内，防止被强行推升至昂贵的企业 Business Plan。
      * 极度符合 1–3 人小团队形态：纯软件/API 中间件与开源生态桥接工具，零重资产、零硬件研发、高粘性 B2B 软件订阅。
