* Unknown Ledger:


   * Known: 全球数以万计安装在商业建筑、医院、学校中的 Tridium Niagara AX 3.8 楼宇自控控制器（Honeywell JACE-600 等）现场硬件与暖通机械运行完好（预期机械寿命 15–20 年）；但随着现代浏览器彻底移除 NPAPI、Oracle 终止 Java Web Start 以及 Windows 10/11 更新破坏 Edge IE 模式，物业与暖通运维人员在现代办公机上完全无法打开 Java Applet 与 Pxg 监控视图，造成“现场运转正常但无法远程操控”的数字锁死；原厂（Honeywell/Johnson Controls）官方方案要求整机升级为 Niagara 4/5（JACE-8000/9000），单台报价高达 $8,000–$25,000（中型设施全套需 $50k–$200k）；现场人员被迫保留未联网的 Win 7 废旧电脑苟延残喘。
   * Unknown: 全球仍在使用 JACE-6 系列且未向原厂提交换代预算的公立机构（学区、市政、中小型医院）与商业楼宇存量总数。
   * Decision-Critical Unknown: 商业楼宇工程主管与暖通设施技师，对于一套“内置受控沙箱浏览器、针对性补丁 JRE 8 环境并自动导入 JACE 自签名证书的免安装绿色 Windows 访问客户端（售价 $99–$149 单授权买断）”的部门小额预算直接采购意愿。


* Gate Checks:


   * Money: 通过。原厂换代单台 $8,000–$25,000，多台改造超十万美元；免安装软件客户端 $149 具备 107 倍杠杆比，物业工程主管可通过日常小额运维费直接报销。
   * Mechanism: 通过。现场控制器坚固耐用（20年），而浏览器前端技术 3–5 年迭代，造成结构性断崖；原厂推销新硬件拒绝维护老系统；绿色便携沙箱客户端在现代 Win 10/11 系统上完全隔离运行且免受系统补丁破坏，技术路径确定可行。
   * Persistence: 通过。公共机构与学校预算审批极度漫长，老旧 JACE 6 仍将服役 5–10 年，对低成本访问维持工具需求长效刚性。
   * Capture: 通过。1-3 人小团队打包免安装绿色运行包与证书自动化导入向导，纯数字软件交付，零实体硬件库存、零现场重安装、高毛利。


* Final Status: HYPOTHESIS_READY
