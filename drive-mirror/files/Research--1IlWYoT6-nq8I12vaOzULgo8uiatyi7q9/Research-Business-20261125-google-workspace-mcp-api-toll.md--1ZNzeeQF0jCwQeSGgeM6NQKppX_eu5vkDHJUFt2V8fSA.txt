Money

Mechanism
在 AI Agent 与 Google 官方 MCP Server（gmailmcp/calendarmcp/drivemcp）之间部署无状态透明代理中间件（严格不持久化留存邮件/文件正文）：


1. 本地 Schema 强预检：拦截必触发 isError: true（HTTP 200 照扣费）的参数错误请求，直接本地返回 4xx；
2. 智能两段式降级：自动将默认 full/raw 请求降级为 metadata/minimal（削减 66% 配额消耗），仅在 Agent 确认命中的线程 ID 后按需拉取正文；
3. 10x 计费循环熔断与项目隔离：实时检测 Agent 死循环重复调用 search_threads / list_drafts 并执行预算熔断，协助团队隔离 Standard（5,000/日免费）与 Scaled 项目。
Capture
1–3 人小团队交付开源核心 + 托管云端 FinOps 控制台（Cloudflare Workers / 自托管 Docker），零客户敏感正文存储风险、极低边际成本、高毛利订阅制。
